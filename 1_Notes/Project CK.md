> ## Subject 2. Autonomous Data Quality and Harmonization Agent for a National Heart Failure Registry
> 
> ### Title
> 
> **Autonomous Data Quality and Harmonization Agent for the Vietnam Heart Failure Registry**
> 
> ### Description
> 
> Develop an agentic system for improving data quality and harmonization in a national heart failure registry. The agent should identify missing data, incorrect units, outliers, duplicates, temporal inconsistencies, coding errors, and cross-hospital data inconsistencies, then recommend or perform corrections under human supervision.
> 
> ### Objectives
> 
> - Design a scalable data-quality pipeline for multi-hospital registry data.
> - Develop rule-based checks for schema, range, unit, temporal consistency, and duplicate detection.
> - Build an AI agent capable of detecting, explaining, and recommending corrections for data-quality problems.
> - Introduce human approval for uncertain or high-risk corrections.
> - Measure error-detection Precision/Recall, correction accuracy, and human-review rate.
> - Evaluate scalability at 100K, 1M, and 10M records.
> 
> ### Deliverables
> 
> - **Solution specification document** describing the problem, requirements, architecture, data flows, algorithms, interfaces, deployment model, and evaluation plan.
> - **Experimental prototype system** with project-specific technical criteria: detecting missing, invalid, duplicated, inconsistent, and outlier registry data; recommending corrections with human approval; evaluated by detection Precision/Recall, correction accuracy, human-review rate, and scalability.
> - **`README.md`** containing instructions for source-code compilation/build, system deployment, configuration, operation, and usage.
> - **LaTeX source** for a **minimum 20-page report in Vietnamese**, formatted using the **IEEE two-column template**, summarizing the project implementation and experimental/evaluation results.
> - **PPTX presentation** containing the project results and designed for an approximately **30-minute presentation**.
